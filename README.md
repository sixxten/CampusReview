# CampusReview

Платформа отзывов студентов о курсах и преподавателях. Студенты выбирают курсы по каталогу с фильтрами, читают структурированные отзывы и оставляют свои; преподаватели ведут свои курсы и отвечают на отзывы; администратор модерирует отзывы, курсы, жалобы и пользователей.

## Стек

| Часть | Технологии |
|---|---|
| Сервер | Node.js, Express, Sequelize, PostgreSQL, JWT (access + refresh в httpOnly-cookie), express-validator, Swagger |
| Клиент | React (Vite), React Router, MobX, axios, собственные UI-компоненты и CSS Modules |
| Инфраструктура | Docker (PostgreSQL) |

## Возможности

**Гость**
- каталог курсов: поиск по названию и преподавателю, фильтры по факультету, семестру, формату, рейтингу и сложности, сортировка;
- страница курса: программа, часы, форматы, агрегированный рейтинг, средние по 5 критериям, распределение оценок;
- отзывы курса с фильтрами по семестру, оценке, наличию текста и сортировкой.

**Студент**
- отзыв-анкета: 5 оценок (полезность, сложность, нагрузка, атмосфера, практическая ценность) и текст; можно анонимно;
- черновики, отправка на модерацию, исправление отклонённого отзыва;
- избранные курсы, жалобы на чужие отзывы;
- кабинет: мои отзывы со статусами, избранное, уведомления, настройки.

**Преподаватель**
- после регистрации ждёт подтверждения администратором;
- создаёт курсы (черновик → модерация → публикация);
- видит отзывы о своих курсах и отвечает на них;
- кабинет: мои курсы со статистикой, отзывы о курсах, уведомления, настройки.

**Администратор**
- модерация отзывов и курсов с указанием причины отклонения;
- жалобы: принять (отзыв скрывается, рейтинг пересчитывается) или отклонить;
- пользователи: подтверждение преподавателей, блокировка и разблокировка;
- счётчики «ждут решения» на каждой вкладке.

## Цепочки статусов

| Сущность | Статусы | Уведомления |
|---|---|---|
| Отзыв | `draft` → `pending` → `published` / `rejected` (с причиной) | автору — о публикации и отклонении, преподавателю — о новом отзыве |
| Курс | `draft` → `pending` → `published` / `rejected` (с причиной) | преподавателю — о публикации и отклонении |
| Жалоба | `new` → `accepted` / `rejected` | автору жалобы — о решении, автору отзыва — если отзыв скрыт |
| Пользователь | `pending` (преподаватель) → `active`, `active` ⇄ `blocked` | о подтверждении и разблокировке |
| Ответ на отзыв | создан / изменён / удалён | студенту — о новом ответе |

Уведомления видны в колокольчике в шапке (счётчик обновляется каждые 30 секунд) и во вкладке «Уведомления» личного кабинета.

## Правила расчёта

- **Итоговая оценка отзыва** = среднее полезности, атмосферы и практической ценности. Сложность и нагрузка в неё не входят: сложный курс не значит плохой.
- **Рейтинг курса** = среднее итоговых оценок опубликованных отзывов; пересчитывается при публикации, удалении и скрытии отзыва.
- **Сложность курса**: ниже 2.5 — низкая, ниже 3.7 — средняя, от 3.7 — высокая.
- Один студент — один отзыв на курс; перед отправкой нужны семестр, все 5 оценок и не меньше 20 символов текста.

## Запуск

### 1. База данных

```bash
docker run --name campusreview-db -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=campusreview -p 5431:5432 -d postgres:16
```

Порт, логин и пароль должны совпадать с `server/config/default.json` (секция `database`).

### 2. Сервер

```bash
cd server
npm install
npm run seed
npm run create-admin -- admin@campus.ru password123 Админ Системы
npm run dev
```

- сервер: http://localhost:5000
- Swagger: http://localhost:5000/api/docs

Таблицы создаются автоматически при запуске (`sequelize.sync({ alter: true })`). Сид можно запускать повторно — дубликатов не будет.

### 3. Клиент

Создайте `client/.env`:

```
VITE_API_URL=http://localhost:5000/api
```

```bash
cd client
npm install
npm run dev
```

Клиент: http://localhost:3000

## Сценарий для демонстрации

1. Гость ищет курс в каталоге и применяет фильтры.
2. Открывает страницу курса, фильтрует отзывы.
3. Студент пишет отзыв, сохраняет черновик и отправляет на модерацию.
4. Администратор публикует отзыв — рейтинг курса пересчитывается.
5. Студент получает уведомление и видит отзыв в кабинете со статусом «Опубликован».
6. Преподаватель отвечает на отзыв — студенту приходит уведомление.

Все запросы видны во вкладке Network браузера: refresh-токен обновляется автоматически при ответе 401.

## API

Документация — Swagger UI на `/api/docs`, спецификация OpenAPI — `/api/docs.json`. Основные группы:

| Префикс | Назначение |
|---|---|
| `/api/user` | регистрация, вход, refresh, профиль |
| `/api/courses` | каталог, страница курса, отзывы и статистика курса |
| `/api/reviews` | отзывы студента |
| `/api/favorites` | избранное |
| `/api/complaints` | жалобы |
| `/api/notifications` | уведомления |
| `/api/teacher` | курсы преподавателя и ответы на отзывы |
| `/api/admin` | модерация и пользователи |
